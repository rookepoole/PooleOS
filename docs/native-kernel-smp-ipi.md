# Native PKSMP3 Capability-Gated IPI Transport

PKSMP3 is the first live PooleKernel inter-processor interrupt transport. It extends the bounded PKSMP2 two-vCPU Sandy Bridge profile with six fixed xAPIC vectors, a 200-byte processor-local mailbox extension, request and response checksums, monotonically controlled attempts and accepted sequences, explicit acknowledgements, and fail-closed capability, vector, stale-sequence, and duplicate-sequence denials.

The live proof starts APIC ID 1 through INIT-SIPI-SIPI, enables interrupts on that AP, and acknowledges one reschedule observation, one transport-only shootdown generation, one fixed allowlisted no-op call, one diagnostic observation, one panic notice, and one stop. It also observes four denied live deliveries, ten EOIs for ten live deliveries, a bounded timeout to offline APIC ID 2, xstate restoration, quiescence, final INIT parking, descriptor and page-table revalidation, capability revocation, and verified scrubbing and release of all 32 low-memory pages.

Page 31 of the PKSMP2 resource image is now a private APIC page table. Its only leaf maps `0xFEE00000` supervisor RW/NX with PWT and PCD. The post-AP validator requires the hardware-set Accessed bits on the PDPT and PD entries and Accessed/Dirty bits on the APIC leaf before cleanup. The bootstrap temporary alias is deliberately returned to the mailbox page before request publication and acknowledgement polling.

The fixed capability is development evidence, not a production secret or authority system. The shootdown operation performs no TLB invalidation or generation retirement. The call-function operation exposes no arbitrary callback. No scheduler, migration, multi-AP, x2APIC, hotplug, NUMA, user workload, PGVM2, PDC, or PooleGlyph dispatch is claimed.

Qualification is generated by `python tools/qualify_native_kernel_smp_ipi.py`. It requires two fresh QEMU runs, exact normalized static markers, exact screenshots and PBP1 bytes, independent request and response checksum models, source audits, and 18 hostile-control groups covering 120 rejected cases. The generated readiness artifact remains pre-production and does not close N8.
