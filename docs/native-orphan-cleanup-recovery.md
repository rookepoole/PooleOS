# Rejected Orphan Cleanup Recovery

Contract PORPHANRECOVERY1, Cycle 312. N13/N14 with N27/N29 consumers.
This is bounded development recovery, not production promotion.

## Ownership And Budget

The ordinary PCLEANUP2 budget remains three dispatch-separated whole-image
attempts, with delays of 64, 128 and 256 dispatches. Only a terminal, authenticated parent can close
its existing non-Clone job. An exact child membership, slot generation, retained
image and quiescent scheduler/accounting state are required to recover an
exhausted child. The raw Slot recovery entry is not public outside task ownership.

A separate single attempt becomes eligible 64 dispatches after exhaustion. It
does not reset the ordinary budget. The opportunity is consumed before memory
access, including error paths. Successful reclamation clears membership only
after release; failure leaves the retained image owned. Repeated observations
cannot rearm it or repeat writes. A dead launch owner receives no completion.

## Native Controls

Use explicit `development-launch-orphan` and optional
`development-launch-orphan-stuck` with the complete launch/quota feature tuple.
Ordinary preview and graphical diagnostic entry points reject these profiles.

The guest first executes useful isolated Text/Numbers file work. A real process
lease causes a quota rejection of Numbers generation 2. Finish faults exhaust
all three ordinary attempts without user entry. The supervisor then cancels the
real shell owner and closes its job; the live Text sibling is reclaimed.

The successful control releases the rejected image after the cooldown. The
persistent-fault control retains it after the one recovery attempt. Both must
show continued init, file-service and window-console progress for at least 512
further dispatches. The persistent control must also show unchanged writes,
zero child calls/ticks, exact retained pages and one remaining child at every
64-dispatch observation. Parse exact job closure, retirement, retry, recovery
and accounting order. Missing, duplicated, rebound or reordered observations
must reject. A synthetic parser fixture is never native evidence.

Paired kernels/ISOs, ordinary unsigned denial, stale-file controls, raw logs,
challenge inputs/results, final framebuffer checks and unchanged source maps
must agree. Do not extend a failed guest deadline or discard its output. Ordinary
desktop regression is separate; no orphan GUI-recovery claim is made.

## Remaining Work

This control cancels the parent through the trusted supervisor; it does not
execute an owner UD2 fault. Actual owner faults, entered-child rescue, multiple
exhausted owners, partial allocator-release failure and construction/committed
handoff recovery need distinct native coverage. Persistent corruption remains
retained rather than repaired. No force-free or unlimited retry is allowed.

Replay the complete QEMU/VirtualBox input/lifetime matrix and produce an immutable
source/runtime-pinned launcher before selecting a replacement preview. Preserve
Cycle308 and every historical receipt. Window-service restart/rebinding,
all-path guarded stacks, COM2-independent startup, persistent storage,
event-driven waits, accessible PooleGlass, PooleGlyph/PDC and all N0-N39 gates
remain. No phase or flag closes merely because this scoped test passes.
