# Native Graphical Launch Recovery

Scope: Cycle310, N13/N14 with N27/N29 consumers. This connects diagnostic
qualification to the existing native PLC1 window controls and Cycle309 kernel
rollback. It does not grant the window manager process-factory authority.

## Admission Boundary

Ordinary `check_preview` always selects the ordinary profile and rejects
diagnostics. Only the explicit QEMU `--launch-failure` test route accepts the
complete launch-shell/launch-console, isolated input and launch-failure profile.
Every required flag must be exactly true; serial recovery must be exactly false.
Missing flags, integer/string aliases and mixed diagnostics reject. The shared
optical checks still require current source hashes, three application controls,
unsigned boot denial, exact image bytes and native marker validation. Unsigned
local evidence is not authentication or a production authorization.

## Graphical Challenge

All ordinary command bytes enter through emulated keys. Every start command is
removed from the terminal scenario and replaced with a GUI action while an
unfinished terminal draft is retained. Text uses the taskbar pointer; Numbers
uses the function key. Both initial starts, both failed second attempts and both
explicit third attempts must be observed. File work proceeds between rejection
and retry. Neither a status string nor a host mock alone proves execution.

The failure barrier requires the kernel's published failure for the exact
task/attempt and rejects admission of that task or a premature third attempt.
Immediately before the effectful button/key event, a separate boundary rejects
any already-observed admission/rejection of that attempt and records scheduler
progress. Reconstruction requires the resulting admission/rejection to be later.
Independent pixel checks require the complete failure label, absent rejected
surface, still-visible peer surface and live terminal. The initiating button/key
remains held, receives a duplicate press, and must retain the same failure view.
Release plus an explicit Inspect gesture must then report absence. A later
fresh Start gesture alone may produce generation3 admission and a fresh surface.
The full native oracle checks partial-grant rollback, exact prepared-image
reclamation, retained-permit publication and independent handle generations.

Every capture, injected event, keyboard transcript, console transcript, raw
kernel log, image and source map is retained. A separate reconstruction checks
the exact action plan, header pixels, surface presence, all raw logs, program
pairs and kernel/ISO identities. Synthetic tests establish runner behavior only.

## Remaining Gates

This diagnostic covers native Denied injection, not native Quota pressure.
Rejected-owner death, cleanup exhaustion, construction quarantine, committed
handoff failure, window-service restart/rebinding and full QEMU/VirtualBox input
and lifetime matrices remain required. The qualified historical Cycle308 preview
is preserved; current-source guards cannot be bypassed. A separate immutable,
versioned launcher bundle remains required so later edits do not strand a demo.
No new preview, physical-hardware qualification, all-path stack proof, persistent
editing, COM2-independent boot, accessible PooleGlass, complete microkernel,
PooleGlyph/PDC integration, canonical merge or production promotion is implied.
