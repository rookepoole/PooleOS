# PooleKernel x86-64

CPU entry, descriptors, faults, interrupts, timers, SMP, context primitives, page-table operations, I/O authorization, and architecture audit fixtures belong here.

`PKENTRY1` begins with `CLI` and `CLD`, verifies the 16-byte direct-jump stack, then calls Rust through the System V AMD64 ABI. PKTRAP1 adds a BSP GDT, 64-bit TSS, five present IDT gates, two bounded IST arrays, normalized integer frames, deliberate returning `#BP`/`#UD`/`#PF`, terminal `#DF`, and semantic malformed-frame denial. PKCPU1, PKXSTATE1, PKXEXC1, PKERR1, and PKMSR1 add support-gated CPU/control-state observation, bounded x87/SSE ownership, selected exception recovery, exact-target rejection, and read-only MSR evidence. PKIRQ1 adds one bounded local-APIC/HPET timer path.

PKSMP1 and PKSMP2 add one-AP startup plus an AP-private GDT/TSS/IDT, guarded stacks, xstate owner, and interrupt-vector runtime. PKSMP5 uses a dynamic `1 << APIC ID` local mask and three private copies of that runtime on a frozen four-vCPU QEMU topology. It proves one partial-start timeout/rollback, fresh retry, fixed-vector development IPI delivery, three generation-bound one-page `INVLPG` operations, aggregate acknowledgement, final INIT parking, and scrubbed release. Scheduler ownership, production capabilities, general topology/shootdown, complete per-CPU activation, target hardware, user mode, and production remain later gates.
